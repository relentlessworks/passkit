passkit

Agentic-first password hashing and verification service. Hash passwords with bcrypt, scrypt, HMAC-SHA256, and SHA-512. Verify passwords, generate tokens, score strength, estimate crack time. Plain text API, agent-driven, single Go binary.

Go bcrypt scrypt HMAC MCP plain-text single-binary

Quick Start

make build && ./passkit

Hash a password

curl -X POST http://localhost:7100/hash/bcrypt -d 'password=secret&cost=12'
